# LocalBiz (Simplified Platform) 🚀

> **"Empowering Every Local Business to Go Digital."**

A simple, fast, zero-build web platform for local businesses built with **HTML5, Vanilla CSS3, Vanilla JavaScript (ES6), and Node.js Express**.

---

## 📁 Repository Structure

```
localbiz-simple/
├── public/
│   ├── index.html       # Landing page & shop browser
│   ├── shop.html        # Digital storefront view (e.g. Kusum Medical)
│   ├── checkout.html    # Order checkout page
│   ├── merchant.html    # Shop owner operations dashboard
│   ├── styles.css       # Master design system (Inter font, CSS variables)
│   ├── app.js           # Frontend logic & Web Speech voice search
│   └── shop.js          # Storefront logic & prescription upload
├── server.js            # Node.js Express API server
├── package.json
└── README.md
```

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start server
npm start
```

Open `http://localhost:3000` in your browser!
